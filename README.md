# 🚀 Repositório de Tópicos Especiais em Programação

Este repositório armazena os materiais, exercícios e projetos práticos da disciplina de Tópicos Especiais. O conteúdo documenta a transição desde a construção de interfaces web estáticas até o desenvolvimento back-end robusto utilizando **Node.js**, **Express** e integração com banco de dados.

## 🗂️ Estrutura do Repositório

O conteúdo está organizado cronologicamente e reflete o avanço progressivo das aulas:

### 🌐 Frontend e Interfaces
* **`aula1` a `aula6_15042026`:** Construção de páginas estáticas e conceitos fundamentais de web envolvendo **HTML** estrutural e desafios lógicos de interface (ex: `cadeado3`).

### ⚙️ Introdução ao Back-end (Node.js & Express)
* **`aula7_13052026` e `aula8_20052026`:** Primeiros passos no ecossistema Node.js. Inicialização de projetos (`package.json`) e criação dos primeiros servidores e rotas web utilizando o framework **Express**.

### 🏗️ Aplicações Dinâmicas, EJS e Banco de Dados
* **`aula10_03062026` a `aula12_17062026`:** Desenvolvimento de aplicações completas abordando:
  * **Template Engine:** Renderização de páginas dinâmicas com **EJS** (`views/index.ejs`, `adicionar.ejs`, `editar.ejs`).
  * **Padrão de Arquitetura:** Implementação do padrão **DAO** (Data Access Object) para separar a lógica de acesso aos dados (`usuarioDAO.js`).
  * **Integração com Banco de Dados:** Conexão com banco de dados (`db.js`) e execução de scripts SQL (`ComandosSQL.sql`).
  * **Segurança e Middlewares:** Interceptação de rotas e validações, como o uso de autenticação/tokens (`validaToken.js`).

## 🛠️ Tecnologias Utilizadas

* **Ambiente de Execução:** Node.js
* **Framework Web:** Express.js
* **Template Engine:** EJS
* **Frontend:** HTML, CSS, JavaScript (Vanilla)
* **Banco de Dados:** SQL
